# Runicsly

Runicsly — шрифт с руническими формами для кириллицы и латиницы.

- [Runicsly](./Runicsly.ttf) – оригинальный шрифт.
- [Runicsly Mono](./RunicslyMono.ttf) – моноширинная версия.

## Подключение на сайте

```html
<link rel="stylesheet" href="https://mixelte.github.io/runicsly/runicsly.css">
```

```css
.title {
  font-family: 'Runicsly', sans-serif;
}

.code {
  font-family: 'Runicsly Mono', monospace;
}
```
